# GR 曲线跨趟身份示例数据

三口井次（trip）各交付一份 LAS，均包含名为 `GR` 的曲线。曲线描述中用
`POS=<UPPER|LOWER>` 记录工具串位置，用 `SN=<序列号>` 记录厂家填写的探头序号。

## 数据场景

- `trip1.las`：一根 GR 探头，单位 gAPI，位于工具串 UPPER，序号 `GR-101`。
- `trip2.las`：一趟两根 GR 探头。
  - `GR[1]`：UPPER，gAPI，厂家只给这一根填了序号 `GR-101`；
  - `GR[2]`：LOWER，gAPI，无序号。
- `trip3.las`：一根 CPS 单位、工具串位置未记录的 GR，外加一根 MV 单位的 GR。

## 解析规则（见 `lasio/curve_identity.py`）

1. 助记名必须一致。
2. 单位可换算（gAPI/CPS 同属伽马族）只是必要条件，不代表传感器相同；
   gAPI 与 MV 不可换算，直接阻断合并。
3. 工具串位置具体时必须一致；位置缺失视为"未知"，不单独阻断，但会制造二义性。
4. 已确认序号是硬证据：同序号必为同一探头，不同序号必为不同探头。
5. 同一趟内的曲线永不合并，因此 trip2 的两根 GR 不可能被认成一根。
6. 枚举所有满足上述规则的整体配对；若存在两种以上配对，把归属不唯一的
   无序号曲线列入"待核"。

## 运行

```bash
python -m lasio.curve_identity trip1.las trip2.las trip3.las
```

期望结果：存在 2 种整体配对。`GR-101` 的跨趟身份确定；
`trip2/GR[2]`（LOWER 无序号）与 `trip3/GR[1]`（CPS、位置未知）为待核曲线；
`trip3/GR[2]`（MV）因单位不可换算而独立成身份。退出码为 1 表示存在待核曲线。
